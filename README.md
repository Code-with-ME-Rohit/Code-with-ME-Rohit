### 🚀 Capstone — SentinelCloud

> An AI-driven autonomous DevOps engineer that thinks before it acts.

**SentinelCloud** is a closed-loop multi-agent system for cloud incident response, FinOps, and shift-left security. Six agents on a finite state machine, three gates (policy, blast radius, calibrated confidence), seven seeded scenarios, and a Word-format capstone report that downloads in one click.

- 🌐 Live: **[sentinelcloud.dmj.one](https://sentinelcloud.dmj.one)**
- 🧠 Real Gemini 2.5 Flash reasoning, ~30–45 s per run, with provider chips on every turn so the demo never lies about who wrote the line.
- 📑 [Pitch deck](https://sentinelcloud.dmj.one/pitch) · [Capstone report](https://sentinelcloud.dmj.one/report) · [Architecture](https://sentinelcloud.dmj.one/architecture)
- 📦 Source: **[Code-with-ME-Rohit/sentinelcloud](https://github.com/Code-with-ME-Rohit/sentinelcloud)**
